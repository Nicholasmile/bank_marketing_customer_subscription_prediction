# Version 2 Ideas

The current project is complete enough for a portfolio. I would treat the ideas below as future extensions instead of delaying publication.

- Use stratified cross-validation for model comparison.
- Test probability calibration before interpreting scores as probabilities.
- Add campaign-cost assumptions and optimize for expected value rather than F1-score alone.
- Compare precision and lift at more call-budget levels.
- Build a small Streamlit interface that ranks uploaded customers.
- Retrain the workflow on newer campaign data if available.
